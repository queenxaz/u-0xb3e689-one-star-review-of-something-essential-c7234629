A deadpan one-star review of gravity, filed in earnest against a force that cannot be fixed.

## The entry

**One star: gravity never takes a day off, yet my phone always lands face-down. No refund offered.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
